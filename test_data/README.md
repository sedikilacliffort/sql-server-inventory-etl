# Test Data

This folder contains synthetic CSV files used to test the SQL Server Inventory ETL workflow.

## Purpose

The files simulate inventory data received from an external source.

They are used to test:
- SSIS CSV file ingestion.
- Data validation rules.
- Duplicate record detection.
- Inventory import processing.
- Batch reconciliation.

## Data Disclaimer

All data is synthetic and created for learning, demonstration, and portfolio purposes.
